张家倩｜互联网创意视觉作品集初版

打开方式：
1. 推荐使用本地服务器打开（模块化3D页面不能直接双击运行）。
2. 在本文件夹启动任意静态服务器后访问 index.html。

本版结构：
- 首页：程序化3D旋转木马、聚光灯、三类作品入口、部件对焦与空间内容卡、可拖动标签。
- 作品：Motion / Product / Worlds 三类筛选，共6个代表项目。
- 档案：教育、实习、能力与联系方式；个人肖像暂留占位。
- 点点互动项目：4条实习产出视频均已加入，可分别点击播放。

后续建议补充：
- 个人肖像或具有个人气质的工作照。
- 每个项目的职责边界、过程稿与最终结果。
- 正式3D木马模型（GLB/GLTF），可替换当前程序化低多边形木马。
- 完整项目页与可下载简历。
