01 / AI 真人＋动画

切入点：等候时的碎片时间

前期构思

将咖啡店等候设为开场，用人物对话建立生活情境，再通过手机特写交代游戏入口。

镜头安排

人物中景 → 手机近景 → 动画玩法。先让观众理解“为什么玩”，再展示“怎么玩”。

02 / 实拍拼豆＋玩法

切入点：手作与游戏的关联

前期构思

围绕“同一图案的两种制作方式”，选择拼豆、熨烫与成品特写，建立实物制作的观看兴趣。

剪辑安排

手部动作 → 成品细节 → 同图案 gameplay。用图形呼应连接实拍与录屏，让玩法切换有依据。

05 / 甜品店风波（272）

策划问题：如何快速升级冲突？

情节拆分

从甜品店的人物互动切入，再安排人物倒下与警方介入，逐次改变观众对事件的判断。

分镜思路

对话交代关系 → 表情特写提示异常 → 事件打断日常。用反应镜头连接人物，让冲突因果可以被读懂。

06 / 火灾后的秘密（236）

策划问题：如何留住悬念？

线索安排

火灾与母亲失踪先建立危机，再用袖扣、文件和人物对话逐步补充信息。

镜头思路

环境交代损失，物件特写强调线索，人物反应保留疑问。每次只释放一部分信息，推动观众继续追问。

07 / 婚礼风波

从承诺到揭露的情绪落差

前期结构

把火灾、婚礼誓言与照片揭示排成连续转折：先建立关系期待，再用新信息推翻判断。

选择节点

在证据出现后接人物反应，让观众先感到意外，再进入关系选择。转折依靠画面信息，而非堆叠解释。

08 / 生育危机与背叛（235）

用平行场景建立关系对照

前期结构

以两位女性的处境为两条线，利用电话把卧室与医院连接起来，逐步暴露人物之间的信息差。

剪辑取舍

通话承担场景转接，表情特写承接情绪变化；关键台词后留出反应画面，让观众读到人物的犹疑。

Fisher’s Voice

课程作业 / 纪录片《渔声》/ 完整片 10:43

选题 / 从劳动经验进入人物

以渔民“抓鱼辛苦”的讲述作为观察入口，让具体的劳动与生活经验支撑人物形象。

采访线索

围绕工作方式、辛苦的环节与生活态度组织问题；保留人物自己的措辞，减少替人物下结论的旁白。

纪录结构

人物出场 → 工作现场 → 个人讲述。现场画面交代环境和动作，采访补充画面之外的经历。
